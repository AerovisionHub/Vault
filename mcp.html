Available Tools

search_institutions
Search FDIC-insured banks by name, city, or fuzzy match. Returns up to 50 institutions ranked by relevance and asset size.
query (required) · state (optional 2-letter code) · limit (default 20)
get_bank_profile
Detailed profile for a single bank by FDIC certificate number. Returns institution details + 8 quarters of financial history.
cert (required) — e.g. "23473"
get_industry_metrics
Aggregate banking industry metrics — total banks, total assets, average ROA/ROE/NIM for any year.
year (optional)
get_recent_charters
List newly chartered FDIC-insured banks (de novo banks) since 2023.
year (optional)
get_ma_activity
List recent bank mergers, acquisitions, and failures. Returns acquirer, acquired, effective date, transaction type.
year (optional) · limit (default 50, max 200)
get_lender_rankings
Banks ranked by composite Lending Score (loan concentration + capital + asset quality + ROA). Filter by state, city, or asset tier.
state, city, loan_type (residential/commercial/smallbiz/consumer), asset_size (community/regional/large)

Why this exists

Banking data is buried in regulatory filings, paywalled aggregators, and 90s-era websites. Vault MCP exposes the same FDIC public data that powers vaultbot.ai to any AI agent — for free, with no API key, and no rate limits beyond what the FDIC enforces upstream.

Built by iDENTIFY, a Tulsa-based fintech data infrastructure company. We help community banks, sponsor banks, credit unions, and fintechs turn their data into a competitive advantage.
