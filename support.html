Connecting Vault

The server address is https://vaultbot.ai/api/mcp. No account or API key is needed.

  • Claude (web, desktop or mobile): Settings → Connectors → Add custom connector, then paste the address.
  • Other MCP clients: use the address directly, or through mcp-remote for clients that only support local servers. The setup guide has copy-and-paste configs.
  • Microsoft 365 Copilot: a Vault listing in Microsoft’s Connectors Gallery is in progress. Email us if your organization would like early access.

Common problems

New tools or options don’t show up

AI assistants remember a connector’s tool list when it’s added. Disconnect Vault and connect it again to load the latest tools.

“spawn npx ENOENT” on Windows

Node.js isn’t installed, or your MCP client can’t find it. Install Node.js, then use the full path that where npx prints instead of just npx.

Edited the config on a Mac and nothing changed

Claude Desktop keeps two similar files in the same folder. MCP servers go in claude_desktop_config.json, not config.json.

It works at home but not at the office

Bank networks often block new domains. Ask IT to allow vaultbot.ai, and registry.npmjs.org if you use mcp-remote.

A request times out

Most tools answer in a few seconds. Multi-year and industry-wide questions take longer the first time and are fast once cached, so try again. Some assistants, such as Perplexity, stop waiting after 15 seconds.
