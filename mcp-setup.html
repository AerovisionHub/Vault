Setup — 2 minutes

  • Install Claude Desktop if you haven't already — claude.ai/download
  • Open your Claude Desktop config file:

    Mac: ~/Library/Application Support/Claude/claude_desktop_config.json

    Windows: %APPDATA%\Claude\claude_desktop_config.json

    Or in Claude Desktop → Settings → Developer → Edit Config.
  • Add Vault to your mcpServers: 
    {
  "mcpServers": {
    "vault-banking": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://vaultbot.ai/.netlify/functions/mcp"
      ]
    }
  }
}

    If you already have other servers, just add the vault-banking entry inside mcpServers.

  • Quit and reopen Claude Desktop (⌘Q on Mac). The first run will install mcp-remote automatically (5-10 sec).
  • Test it. Click the tools icon below the chat input — you should see vault-banking with 6 tools.
