Setup — 30 seconds

Claude connects to Vault directly now — no config file, no terminal, no restart. Works in Claude on the web, desktop and mobile.

  • Open Claude and go to Settings → Connectors.
    On Team or Enterprise plans an Owner adds it once under Organization settings → Connectors, then everyone clicks Connect.
  • Click "Add custom connector" and paste this URL: 
    https://vaultbot.ai/api/mcp
  • Set Authentication to "No sign-in."
    Vault is free and public — there's no account and nothing to log into. If Claude pre-fills something else, change it to No sign-in, or the connection will fail while it looks for a login that doesn't exist.
  • Click Add, then turn Vault on in the chat's "+" menu under Connectors. You should see vault-banking with 18 tools.

Claude Code

One line in your terminal:

claude mcp add --transport http vault https://vaultbot.ai/api/mcp

Add -s user to make it available in every project. Check it with /mcp.

Older Claude Desktop (config file)

Only needed if your Claude Desktop predates custom connectors. This route bridges through mcp-remote, which reconnects often — prefer the connector above if you have it.

  • Claude Desktop → Settings → Developer → Edit Config, then add: 
    {
  "mcpServers": {
    "vault-banking": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://vaultbot.ai/api/mcp"
      ]
    }
  }
}
  • Quit and reopen Claude Desktop (⌘Q on Mac).

Available tools

Vault MCP exposes 18 tools to your Claude agent:

  • Find institutions: search_institutions (banks and credit unions)
  • Bank financials and history: get_bank_profile, get_asset_quality_detail, get_loan_mix, get_brokered_deposits, get_branch_data
  • Credit unions: get_credit_union_profile
  • Markets and geography: get_county_deposit_share, get_county_demographics, get_hmda_lending, get_lender_rankings
  • Industry activity: get_industry_metrics, get_recent_charters, get_ma_activity
  • Who to talk to: get_bank_leadership, get_bank_leadership_bulk, trigger_linkedin_match, check_linkedin_match

Full tool documentation at vaultbot.ai/mcp.
